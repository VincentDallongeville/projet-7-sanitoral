\# Projet 7 – Sanitoral



Projet réalisé dans le cadre de la formation Data Analyst (OpenClassrooms).



\## Objectif



Créer un tableau de bord Power BI pour le suivi des indicateurs de Sanitoral.



\## Contenu



\- `data\_raw/` : données brutes Excel.

\- `doc/` : documents de cadrage.

\- `powerbi/` : tableau de bord Power BI.

\- `presentation/` : supports de présentation.



\## Outils



\- Power BI

\- Excel

\- Git / GitHub



\## Lancement



Ouvrir `powerbi/tdb\_sanitoral.pbix` avec Power BI Desktop.
